# СКМ — информационный сайт

Сайт ООО «СКМ» на Next.js 16 показывает услуги, ориентировочные цены и способы связи. Публичных аккаунтов, оформления заказов и формы заявки нет.

## Разработка

```bash
npm ci
npm run dev
npm run lint
npm run build
```

Локальный адрес: `http://localhost:3000`.

## Содержимое и контакты

- Услуги и цены можно менять через закрытую панель `/admin`.
- Телефон и email заданы в `lib/site-config.ts`.
- Кнопки «Связаться» открывают выбор email или звонка. Сайт не загружает Jivo.
- Публичная политика обработки персональных данных находится на `/politika`. Она нужна, поскольку компания получает обращения с контактными данными по email и телефону. Перед публикацией юридических изменений проверьте её соответствие фактическим процессам ООО «СКМ».

## Администрирование

Вход на `/login` доступен только для адресов из `ADMIN_EMAILS` или `ADMIN_EMAIL`. Одноразовый код отправляется через Resend. После входа администратор открывает `/admin`; дополнительный пароль панели сохраняется. Укажите `AUTH_SECRET` и настройки отправки кода в окружении хостинга.

Публичная регистрация закрыта на уровне серверных действий. Старые страницы `/account` и `/checkout/*` удалены. Сохранённые ранее данные в базе не удаляются автоматически; их сроки хранения и удаление нужно определять отдельно.

Timeweb App Platform развёртывает ветку `main` Git-репозитория. После изменения кода требуется новый деплой из репозитория и проверка страниц сайта.
